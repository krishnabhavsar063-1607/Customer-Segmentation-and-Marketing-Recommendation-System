# 🛍 Customer Segmentation & Marketing Recommendation System

## 📌 Overview

This project uses **K-Means Clustering** to segment customers based on their annual income and spending behavior. The system helps businesses identify different customer groups and create targeted marketing strategies.

An interactive **Streamlit Dashboard** is included for visualization, customer prediction, and business analytics.

---

## 🚀 Features

* Customer Segmentation using K-Means Clustering
* Automatic Best Cluster Selection (Silhouette Score)
* Interactive Streamlit Dashboard
* Customer Type Prediction
* Marketing Recommendations
* Age & Gender Analysis
* Cluster Visualization
* Download Segmented Customer Data

